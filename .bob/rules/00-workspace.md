# Workspace rules for main (mandatory)

- This folder holds the experiment, not the game.
- You may run `python3 measure.py` (it builds copies in a temporary folder and writes only to `results/`), and `mvn`, `java`, `jdeps` and `javap`.
- You may read, but never edit, the two experiment folders `../without-ddd` and `../with-ddd` (next to this folder). Do not touch anything else outside this folder.
- You may use git here only to read (`git log`, `git show`, `git diff`, `git status`). Never commit, checkout, reset, merge or push.
- Do not use the network beyond what Maven needs.
- Never ask questions or wait for confirmation; finish the task on your own.
